Rohit Sharma --- Cricket Performance Analytics Dashboard

📊 Project Overview

This project is an end-to-end Cricket Performance Analytics project built using Python, Pandas, NumPy, Matplotlib, Seaborn, Power BI, and DAX.

The project analyzes a 1,000-record cricket performance dataset and presents insights through exploratory data analysis and an interactive Power BI dashboard.

🎯 Project Objectives

The main objectives of this project are to:
Clean and prepare cricket performance data.

Perform exploratory data analysis using Python.

Analyze batting performance across years and formats.

Identify performance patterns across opponents and grounds.

Analyze wins, losses, and dismissal types.

Create meaningful visualizations using Matplotlib and Seaborn.

Build an interactive Power BI dashboard using DAX measures and slicers.
